# Virtufin Workers

This repository is a **deployment target only**, holding the built,
published documentation site for **Virtufin Workers**. Published at https://workers.docs.virtufin.com/.

Source: [virtufin-workers](https://git.haenerconsulting.com/virtufin/virtufin-workers)

Content on the `gh-pages` branch is generated by CI (MkDocs) and is
**fully replaced on every deploy** (the publish step does `rm -rf` +
force-push) -- never edit `gh-pages` directly, changes will be lost
on the next publish.

This README lives on `main`, kept separate from `gh-pages`
specifically so it survives those deploys -- `main` is not part of
the published site.
